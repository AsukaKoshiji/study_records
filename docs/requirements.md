# 要件定義書

## システム概要
学習記録を管理するWeb APIアプリケーションを作成する

## 目的
学習内容学習内容をカレンダーに記録・目標設定・進捗確認できるようにする

## 使用技術
- FastAPI
- MySQL
- Docker
- Poetry

## 機能要件

### 目標設定
１日、１ヶ月単位で目標を設定・表示できる

### 学習内容記録
１日の学習内容を記録・表示できる。

### 進捗確認
カレンダーからその日の進捗を確認できる

## 非機能案件


### API
REST API形式で実装する

### DB
NySQLを使用する

### 開発環境
Dockerで起動できるようにする
